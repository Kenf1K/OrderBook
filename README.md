 OrderBook
Сделал мини криптодвижок с матчингом на 350000 ордеров в секунду

## Архитектура  
Вначале создаем ордер, который попадает в очередь(FIFO), в последствии ордер попадает извлекается из очереди и попадает в книгу ордеров в зависимости от его типа(buy/sell),   
когда ордер попадает в книгу, после чего сортируется и происходит сравнение в системе матчинга, если цена покупки равна или больше цены продажи, ордера обрабатываются и потом удаляются  

## Стек: C++17,STL,потоки  

Скорость алгоритма матчинга O(n),способен обработать ~320-350к ордеров в секунду, делая 5 замеров, через среднее арифмитическое мой матчинг способен обрабатывать максимально 370к ордеров в секунду,  
однако цифры неточные и погрешность может иметься, для комфортной работы, для такого медленного алгоритма, нужно примерно 315к ордеров(расчеты повторюсь могут иметь погрещности, при проверке, стабильно 315к ордеров, алгоритм обрабатывал за 0.82 секунды)

Логирование осуществляется простым способом, простой записью информации в csv файл перед каждым удалением ордера из книги


## Как запустить:
mkdir build && cd build
cmake ..
cmake --build .
